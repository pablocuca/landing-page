Perguntas frequentes

Como funciona a repetição espaçada?

GameNow usa o algoritmo SM-2 (SuperMemo-2) para trazer de volta as palavras que você ainda não domina. Palavras que você acerta com frequência voltam mais devagar. Palavras difíceis voltam logo, para reforçar a memória.

Como mudo meu nível CEFR?

Vá em Configurações (⚙️) → Nível CEFR e selecione outro nível. O app prioriza palavras do seu nível e um nível acima (estratégia i+1 de Krashen).

Meus dados são sincronizados com a nuvem?

Não. GameNow é 100% offline e local. Seu progresso (palavras estudadas, quizzes respondidos, estatísticas) fica armazenado apenas no seu dispositivo usando UserDefaults do iOS. Nenhum dado é enviado para servidores remotos.

Como apago meus dados?

Desinstale o app. Seus dados locais serão deletados automaticamente. Não há conta de usuário na nuvem para limpar.

Qual é a diferença entre os pacotes gratuitos e pagos?

O pacote gratuito (free-core) tem 50 palavras essenciais de negócios e cotidiano. Pacotes pagos adicionais incluem temas como viagem, business avançado, phrasal verbs, etc. Você pode estudar com o pacote gratuito indefinidamente.

Como reporto um bug?

Envie um email para apple@pablocustodio.com.br com:

  • Descrição clara do problema (o que aconteceu?)
  • Modelo do dispositivo e versão do iOS (Configurações → Geral → Sobre)
  • Versão do GameNow (Configurações → Sobre → Versão)
  • Passos para reproduzir o problema

Posso sugerir uma feature?

Claro! Envie suas ideias por email. Leio todas as sugestões e considero para versões futuras.

O app tem publicidade?

Não. GameNow não tem anúncios e nunca terá. Usa um modelo de compra única por pacote (freemium) e doação opcional.

O app funciona offline?

Sim, 100%. Não precisa de internet para jogar ou estudar. Seu progresso é salvo localmente.

Há suporte para outros idiomas?

Atualmente, GameNow é apenas para aprender inglês. Mas inglês é o idioma mais falado do mundo, então é um bom começo! :)

Como funciona a compra de pacotes?

Pacotes adicionais são comprados via App Store (StoreKit 2). Após a compra, você tem acesso permanente a todas as palavras daquele pacote. Não há assinatura obrigatória — é uma compra única.

Problemas comuns

O app não aparece no meu perfil do Family Sharing

Se você comprou o app com uma conta diferente, ele não sincroniza automaticamente com outras contas. Você pode restaurar a compra: Configurações → [Seu nome] → iTunes e App Stores → restaurar compras.

O quiz de pronúncia não funciona

Verifique se:

  • O microfone está habilitado em Configurações → GameNow → Microfone
  • Seu dispositivo tem microfone funcionando (iPhone/iPad)
  • Tente reiniciar o app

Não consigo restaurar minha compra

Restaurar compras funciona apenas com a conta Apple ID que fez a compra original. Se comprou com outra conta, faça login com aquela conta (Configurações → [Seu nome] → iTunes e App Stores).
